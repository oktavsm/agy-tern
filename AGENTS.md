# agy-tern

Bun + TypeScript frontend. ACP v1 connects to the official `agy acp --sandbox` subprocess; Tern Surface Protocol draws the native UI. Read README.md for the trust boundary and commands.

Keep authentication, tools and Google traffic inside the official CLI. Advertise only implemented ACP capabilities. Permission choices must use server-provided IDs; cancellation and shutdown resolve pending requests as cancelled. Existing Antigravity permission rules still apply. Requesting `--sandbox` does not establish that OS containment is available.

Use Tern semantic kinds and theme tokens, not a second style system. Native chat should remain usable by keyboard. Other terminals delegate to the official UI.
